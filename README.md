# Horizon Launcher — Offline Setup Guide

## How to play without a Microsoft account

Horizon downloads Minecraft 26.3 automatically every time the launcher starts.
No account needed for the download — it comes straight from Mojang's servers.

---

## Steps

### 1. Create an offline account
- Open the launcher
- Click your name in the top bar (shows **Offline**)
- You are already offline — no sign-in needed

### 2. Download and prepare the game
- On the Home page, click the **⋯** button next to Play
- Click **Prepare**
- Wait for the progress bar to finish:
  - ✅ Game files
  - ✅ Java
  - ✅ Sounds
  - ✅ Prepare

### 3. Play
- Once preparation is done, the **Play** button becomes active
- Click **Play** and enjoy

---

## Notes
- If `.minecraft` is deleted, the launcher re-downloads everything automatically on next boot
- No Microsoft account required
- Downloads use Mojang's official Piston API
